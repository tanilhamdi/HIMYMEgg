# 📺 HIMYMEgg

A custom Svelte application designed to pick random *How I Met Your Mother* episodes from a curated list (`himym.txt`), featuring a sleek dark-mode UI and a special easter egg[cite: 1].

---

## 🚀 Features

- **Random Episode Picker:** Uses Lodash (`lodash`) to randomly select an episode index from `himym.txt` and redirect the user instantly[cite: 1].
- **Easter Egg Handling:** Triggers a special display screen when a specific index (`208`) is hit[cite: 1].
- **Custom Dark UI:** Styled with a polished dark theme, centered flex containers, and custom transitions using native CSS[cite: 1].

---

## 🛠️️ Tech Stack

- **Svelte** (with TypeScript support)
- **Vite** (Build tool)
- **Lodash** (Random utility functions)
- **FontAwesome** (Icons)

\`\`\`bash
